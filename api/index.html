How payment works

Standard x402. Call the endpoint without payment. The server answers 402 Payment Required with the requirements. Pay in USDC on BNB Chain. Retry with the receipt.

{
  "scheme": "x402",
  "network": "eip155:56",
  "asset": "0x8ac76a51cc950d9822d68b83fe1ad97b32cd580d",
  "assetSymbol": "USDC",
  "payTo": "0xe905752828DB27A9b5a07BB77091CDc5F5728144",
  "maxAmountRequired": "20000000000000000"
}

USDC on BNB Chain uses 18 decimals. 0.02 USDC is 20000000000000000.

What this service does NOT do

Read this before you buy.

• It does not prove a token is safe.
• It does not measure the transfer tax. Tax requires simulating a buy and a sell. A static read cannot see it. The API returns "status": "unknown" rather than guessing.
• It does not predict price, and never will.
• Every response carries a limitations field. It is not decorative. Read it.

Why we publish our own limits

Most scanners return a green "safe" score, which implies a guarantee static analysis cannot give. This one returns its checks, the evidence for each, and the ones it cannot answer. Run it on our own token and it returns 8/10, not 10/10 — because two checks genuinely cannot be resolved by reading bytecode.
